# Plunger sounds

The two plunger banks of the mechanical sound set in the asset library (`org.visualpinball.unity.assets`, `Assets/Sounds/Mechanical`). They live here because the default Plunger prefab (`Resources/Prefabs/Plunger.prefab`) uses them, so the player doesn't need the asset library.

Fleep mechanical samples extracted without audio processing from `Terminator 2 (Williams 1991) g5k 1.25.vpx` by g5k. Original sample filenames are retained for traceability. Credit the original table and sample authors when redistributing; the engine's code license does not grant additional rights to audio recordings.
